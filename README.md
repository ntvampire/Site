# Site — Каталог проектов на GitHub Pages

Автоматически обновляемая витрина ваших репозиториев на GitHub Pages с минималистичным тёмным дизайном.

## Возможности

- 🕒 **Автообновление по расписанию:** Запускается каждое утро в `03:37 UTC` (нестандартное время, без задержек в очередях GitHub Actions).
- ⚡ **Триггер при пушах в другие проекты:** Поддержка `repository_dispatch` (см. [DISPATCH_GUIDE.md](DISPATCH_GUIDE.md)).
- 🔘 **Ручной запуск:** Кнопка **Run workflow** во вкладке *Actions* на GitHub.
- 🎨 **Минималистичный дизайн:**
  - Глубокая матовая тёмная тема (без градиентов).
  - Никаких метрик (звёзды и форки скрыты).
  - Чистые карточки: название, описание, стек/топики, дата обновления, ссылка на код и на демо (если указан Homepage в настройках репо).
- 🔍 **Мгновенный поиск и фильтрация:** По названию, описанию и языкам программирования прямо в браузере.
- 🚫 **Управление видимостью:**
  - Форки и архивированные проекты скрываются автоматически (настраивается).
  - Чтобы скрыть конкретный проект, просто добавьте ему в GitHub топик `portfolio-hide` (или укажите его имя в переменной `EXCLUDE_REPOS`).

## Настройка GitHub Pages

1. Создайте репозиторий с именем `Site` на GitHub и запушьте в него эти файлы.
2. Откройте **Settings** репозитория -> раздел **Pages**.
3. В выпадающем списке **Source** выберите **GitHub Actions**.
4. Перейдите во вкладку **Actions**, выберите воркфлоу *Deploy Projects Showcase to GitHub Pages* и нажмите **Run workflow** (либо дождитесь первого ночного запуска или пуша).

После первого выполнения сборки сайт будет доступен по адресу:
`https://<ваш_юзернейм>.github.io/Site/`
*(или `https://<ваш_юзернейм>.github.io/`, если репозиторий назвать `<username>.github.io`)*.
